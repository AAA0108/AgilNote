# AgilNote

テキストファイルの小説を、横書き・縦書きで読みやすく表示するビューアです。
ブラウザで動き、Windows やスマホにアプリとして入れられます。

**開く:** https://aaa0108.github.io/agilnote/

## できること

- `.txt` を開く（ボタン、ドラッグ＆ドロップ、本文の貼り付け）。UTF-8 と Shift_JIS を自動判別
- 横書き／縦書きの切り替え。ルビ（`|漢字《かんじ》`）と「！？」の縦中横に対応
- 見え方のプリセット：投稿サイト風／チャット画面風／文庫風
- 文字の大きさ・行間・段落間・行の長さ・書体の調整（設定は自動で保存）
- 手持ちのフォント（.ttf / .otf / .woff / .woff2）の追加。追加した書体は端末内に保存
- 文字数、台詞段落の割合、地の文の平均の長さ、12字以下の地の文の数を表示
- 一度開けばオフラインでも動作

読み込んだ本文やフォントは端末の中で扱うだけで、どこにも送信しません。

## アプリとして入れる

### Windows（Edge / Chrome）

1. 上の住所を Edge か Chrome で開く
2. アドレスバー右端の「アプリをインストール」アイコンを押す（Edge は「…」メニュー →「アプリ」→「このサイトをアプリとしてインストール」）
3. スタートメニューに AgilNote が入ります

**.txt を AgilNote で開く:** インストール後、.txt を右クリック →「プログラムから開く」→ AgilNote。
初回はブラウザが「このファイルを開くことを許可しますか」と確認します。
既定のアプリにするなら、Windows の「設定」→「アプリ」→「既定のアプリ」で .txt に AgilNote を選びます。

### Android（Chrome）

住所を開き、メニュー →「ホーム画面に追加」または「アプリをインストール」。

### iPhone / iPad（Safari）

住所を開き、共有ボタン →「ホーム画面に追加」。
iOS では「このアプリで開く」には対応しないので、アプリ内の「ファイルを開く」から読み込んでください。

## 更新するとき

`index.html` などを変えたら、`sw.js` の先頭の `VERSION` を上げてから push します（例：`agilnote-v1` → `agilnote-v2`）。
次に開いたとき、新しい版に入れ替わります。
