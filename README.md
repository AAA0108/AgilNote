# AgilNote

テキストファイルや Markdown の小説を、横書き・縦書きで読みやすく表示するビューアです。
ブラウザで動き、Windows やスマホにアプリとして入れられます。

**開く:** https://aaa0108.github.io/AgilNote/

## できること

- `.txt` と `.md`／`.markdown` を開く（ボタン、ドラッグ＆ドロップ、本文の貼り付け）。UTF-8 と Shift_JIS を自動判別
- 拡張子で「テキスト／Markdown」を自動で選び、上部の形式欄でいつでも切り替え可能
- 横書き／縦書きの切り替え。ルビ（`|漢字《かんじ》`）と「！？」の縦中横に対応
- 見え方のプリセット：投稿サイト風／チャット画面風／文庫風
- 文字の大きさ・行間・段落間・行の長さ・書体の調整（設定は自動で保存）
- 上部メニューの開閉。右上の「たたむ」で書名だけの細い帯になり、本文を広く使える（キーボードの M でも切り替え。状態は自動で保存）
- 手持ちのフォント（.ttf / .otf / .woff / .woff2）の追加。追加した書体は端末内に保存
- 文字数、台詞段落の割合、地の文の平均の長さ、12字以下の地の文の数を表示
- 一度開けばオフラインでも動作（本体と Markdown 表示は同梱。標準の書体は一度表示したものを保存）

## Markdown の表示

`.md` は Markdown として整形して表示します。`.txt` は従来どおりプレーンテキストのままです。

- **改行は小説の流儀**：一般的な Markdown と違い、本文の 1 行を 1 段落として表示します。続けて書いた台詞がつながることはありません。全角の字下げと空行もそのまま残ります。
- 見出し、太字、強調（傍点で表示）、取り消し線、水平線（場面転換）、リスト、表、引用、コード、リンクに対応
- ルビ（`｜漢字《かんじ》`・`|漢字《かんじ》`・`漢字《かんじ》`）と縦中横は従来どおり。コードの中には適用しません
- 縦書きでは、表とコードは横組みの枠に入れて、はみ出す分はその枠の中でスクロールします
- `≪System≫` や `【アンケート】`、判定の表なども本文として必ず表示します。見出し名などから推測して隠すことはしません
- 入力の HTML は実行せず、文字として表示します。リンクは `http`・`https`・`mailto` だけを開けるようにしています
- 表の中でルビを使うときは、全角の `｜` を使ってください（半角の `|` は列の区切りになります）

### 内部記録を隠す

次の 2 行で囲んだ範囲だけを、読書表示では隠します。元のファイルは書き換えません。

```md
<!-- agilnote:internal:start -->
## GM向け次話引継ぎ
次月の未処理事項など
<!-- agilnote:internal:end -->
```

- 上部の「読書表示／全文表示」で切り替えます。全文表示では、点線の枠の中に隠した内容が出ます
- 目印は、それだけを書いた行で完全に一致したときに有効です。コードの中や文の途中に書いたものは目印になりません
- 開始と終了の対応が崩れている（片方だけ、入れ子、順番が逆）ときは、何も隠さずに全文を表示し、警告を出します
- `.txt` では目印も普通の文字として表示します

### 統計（Markdown のとき）

- 文字数：画面に出ている文字（Markdown の記号は数えません）
- 本文段落・台詞段落・地の文の平均・12字以下の地の文：本文の段落だけで計算します
- その他：見出し・表・リスト・引用・コードの文字数を別に表示します
- 内部記録：どちらの表示でも統計には含めず、件数だけ表示します

`samples/markdown-sample.md` に、表示を試せる短い見本があります。

読み込んだ本文やフォントは端末の中で扱うだけで、どこにも送信しません。

## アプリとして入れる

### Windows（Edge / Chrome）

1. 上の住所を Edge か Chrome で開く
2. アドレスバー右端の「アプリをインストール」アイコンを押す（Edge は「…」メニュー →「アプリ」→「このサイトをアプリとしてインストール」）
3. スタートメニューに AgilNote が入ります

**.txt や .md を AgilNote で開く:** インストール後、ファイルを右クリック →「プログラムから開く」→ AgilNote。
初回はブラウザが「このファイルを開くことを許可しますか」と確認します。
既定のアプリにするなら、Windows の「設定」→「アプリ」→「既定のアプリ」で .txt や .md に AgilNote を選びます。
（.md の関連付けは、この更新後にアプリを開き直すと加わります。加わらない場合は一度アンインストールして入れ直してください）

### Android（Chrome）

住所を開き、メニュー →「ホーム画面に追加」または「アプリをインストール」。

### iPhone / iPad（Safari）

住所を開き、共有ボタン →「ホーム画面に追加」。
iOS では「このアプリで開く」には対応しないので、アプリ内の「ファイルを開く」から読み込んでください。

## 更新するとき

試験は `node tests/md.test.js` で実行できます。

`index.html` などを変えたら、`sw.js` の先頭の `VERSION` を上げてから push します（例：`agilnote-v1` → `agilnote-v2`）。
次に開いたとき、新しい版に入れ替わります。
